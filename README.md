
# Lab 7: Image Segmentation and Feature Extraction

This lab demonstrates three image processing techniques using Python and OpenCV:

- **Canny Edge Detection**: detects edges in an image.
- **Harris Corner Detection**: detects important corner points.
- **Otsu’s Thresholding**: automatically selects a threshold to segment an image into foreground and background.

## Libraries Used
- OpenCV
- NumPy
- Matplotlib
- scikit-image

## How to Run
Open the notebook in Jupyter Notebook or JupyterLab and run all cells from top to bottom.

## Conclusion
The lab shows how edges, corners, and image regions can be detected and extracted from digital images.
